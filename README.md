# 日语小步走

**双击「一键启动.cmd」→ 选择当前课 → 开始学习。**

适合 Windows PC 的个人日语学习工具。对齐《大家的日语》第二版初级 I、II，共 50 课。浏览器访问 `http://127.0.0.1:4317`，学习记录留在本机。

也可部署成个人网站：双击 **deployment-guide.html** 查看五步可视化指引；完整命令见 [阿里云部署说明](docs/deployment.md)。`npm.cmd run package:web` 生成不含个人记录和密钥的源码部署包。服务器版使用 HTTPS 和网页登录密码，记录保存在自己的服务器；无需保持家中电脑开机。

代码仓库：[minnanonihongo_helper](https://github.com/MAXGUAN-Game/minnanonihongo_helper)。后续迭代、版本标签和服务器更新约定见 [版本管理说明](docs/version-control.md)。推送代码不会自动部署到服务器。

服务器已有其他网站时，优先使用 [共存部署](docs/deployment-shared.md)：单独的 `jp.nbblearnjp.xyz` 站点，沿用现有 HTTPS 网关；`compose.shared.yaml` 只绑定本机端口，避免抢占原站的 80/443。

## 第一次使用

1. 安装 [Node.js 24 LTS](https://nodejs.org/)，已安装可跳过。
2. 双击 **一键启动.cmd**。首次会安装依赖并准备页面，随后自动打开浏览器。
3. 在页面选择当前课，填写自己的 DeepSeek API 密钥，测试麦克风。没有密钥也能学习课程和复习。
4. 用完后双击 **一键停止.cmd**。只关闭浏览器不会停止本机服务。

本机语音模型首次在后台下载，约 0.5 GB。下载中或失败时先用文字输入；可双击 **安装本机语音.cmd** 重试。已经下载的模型后续无需重复下载。

## 每天怎么练

**看懂 → 听懂 → 自己说 → AI 对话 → 复习卡点**

- 每课精选词卡、语法图解、短对话听力、开口任务和两个 AI 场景。六个开口任务先看范句，再看关键词，最后独立表达。
- 每课另有 **语法自由聊**：可选整课或一个语法点，用中文问问题、请 AI 举例，或用日语接着聊；默认先看日语，需要时点“看中文”或“听讲解”。
- 首页继续上次进度，也能在课程地图自由选课；提供 60 分钟安排和 15 分钟短练。
- 区分看过、借助提示、独立完成；自己确认的卡点才进入复习，按表现安排下次复习。
- 界面支持大字、注音、中文讲解朗读和日语句子朗读；说明可以展开查看。
- 按住录音或点击开始／结束，确认转写后才发送给 AI；也可以直接打字。听不懂时点重复、慢一点、提示或中文。

## 语法想不通时

1. 打开这一课的 **用起来 → 语法自由聊**。
2. 选择“本课全部语法”或一个语法点，点 **开始语法自由聊**。
3. 输入问题，或点 **解释这个句型／给我一个例子／陪我练一句**，确认后发送。

日语录音仍在本机识别；中文问题可以打字。日语点“再听一次”，中文按需点“看中文”或“听讲解”，新回复和刷新后默认收起中文。自由聊不会在第 6 轮结束，想休息时点“结束这轮”；返回练习选择或刷新页面会保留未发送的文字。交流不会自动算作已掌握。

完整对话保存在本机。为控制请求大小，AI 每次参考本课资料与最近 12 轮交流；更早的内容仍可在页面查看。一次自由聊最多 200 轮，之后可新开一次。

## 数据与语音

学习记录和设置在项目的 `data/` 目录。页面的**设置 → 导出／恢复学习记录**用于备份与恢复；导出的备份不包含 API 密钥。移动项目时请连同 `data/` 一起移动，并先停止服务。

DeepSeek 收到当前练习所需的文字上下文；密钥保留在本机后端。录音在本机由 whisper.cpp 转成日语文字，处理后删除原始音频。默认使用本机中文和日文系统声音朗读；缺少声音时，按设置页指引安装 Windows 语言语音包。

本应用的课程、复习和系统朗读可离线使用。AI 对话需要网络、有效密钥和账户额度。本机语音识别需要首次下载模型；CPU 可以运行，实际耗时取决于电脑性能。

### 更自然的日语声音

在 **学习设置 → 更自然的日语声音** 选择 **云端 AI 声音 · MiniMax**，填入自己的 **MiniMax API 密钥**，点 **保存并试听**。密钥与 DeepSeek 分开，留空保存会保留原密钥；不要把密钥发到聊天里。

没有密钥时，登录 [MiniMax 开放平台](https://platform.minimax.cn/)，确认语音服务额度，在 API 密钥管理中创建密钥。参见 [官方语音说明](https://platform.minimax.cn/docs/api-reference/speech-t2a-http) 与 [套餐、额度](https://platform.minimax.cn/subscribe/token-plan)。具体账户和密钥能否调用，以平台说明及实际试听结果为准。

可选温柔女声、沉静女声、知性前辈、温和管家，为对话双方选择不同声音，并调整三档语速。默认 Speech 2.8 HD，也可切换较快的 Turbo。MiniMax 会接收需朗读的日语文字，输出 AI 合成声音，联网费用按自己的语音服务账户计算。中文讲解继续用本机声音；云端失败会提示，并尝试本机朗读。相同文字、音色、质量、语速可复用本机缓存，设置页可查看与清理。

## 内容与边界

这是原创辅助练习，配合纸质教材学习。覆盖 50 课主要目标，每课至少 10 个重点词、每组语法两句例句、两段短对话、六个开口任务、两个场景；词卡是精选复现，不是教材完整词表，也没有复制教材全文或整套习题。来源说明见 `src/content/SOURCES-SECOND.md` 及内容目录中的来源记录。

听力使用系统或云端 AI 合成语音，**不是教材原版录音**。转写可以出错，发送前请确认；应用不提供发音评分。AI 示例答案不是唯一答案，模型纠错仍可能有误。真实 DeepSeek、MiniMax 联调需填写用户自己的密钥后验证；自动测试使用模拟接口，不消耗 API 额度。

## 维护与排查

在项目目录用 PowerShell 运行：

```powershell
npm.cmd install
npm.cmd run build
npm.cmd start
npm.cmd test
npm.cmd run test:e2e
npm.cmd run setup:speech
```

- 启动日志：`data/server.log`、`data/server-error.log`。
- 语音安装日志：`data/speech-install.log`、`data/speech-install-error.log`。
- 端口被其他程序占用时会提示，不会抢占或结束其他程序。
- 重复启动会打开已运行的应用；更新代码后先停止再启动，会按文件更新重新构建。
- 开发检查可用 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start.ps1 -NoBrowser -SkipSpeechSetup`。

技术栈：React、TypeScript、Vite、Fastify、SQLite。默认本机模式仅监听 `127.0.0.1`；显式配置的服务器模式通过带认证的 HTTPS 代理访问。网站是个人共享一份记录的学习工具，没有多人独立账号、自动跨安装同步、PDF 导入或实时通话功能。
