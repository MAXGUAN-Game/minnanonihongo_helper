# スーパーミンナノニホンゴ

配合《大家的日语》第二版初级 I、II 使用的个人学习工具，共 50 课。

最新版本 **v1.4.1**：[升级校验修复与服务器重试步骤](docs/v1.4.1-release.md)。本地源码包与远程网站分别更新，打包不会自动部署。

## 本地使用

安装 Node.js 24.5 或更高版本，双击「一键启动.cmd」，浏览器打开 `http://127.0.0.1:4317`。更新源码后先双击「一键停止.cmd」，再启动，以免新版页面连到旧后台。开发时也可运行：

```powershell
npm.cmd install
npm.cmd run build
npm.cmd start
```

左侧为「50课地图」「片假名」「设置」。每课分为单词、语法、听力、口语：

- 单词列表包含 50 课共 2,258 个词和固定表达，中文默认隐藏，可逐词或全部显示。点击词语可查看解释、例句、假名和罗马音；例句语法按需分析。词语旁支持 AI 发音。词库按课加载，[来源与数量核对](docs/v1.3.0-vocabulary-audit.md)随源码提供。
- 单词 AI 练习要求用当前词造句，支持拼写或录音。所有拼写练习回车提交，答对后再次回车进入下一题；也可开启「回车答对自动下一题」。开关在浏览器记住，点击检查按钮仍停留本题；多行输入支持 Shift+Enter 换行。
- 语法沿用讲解和例句，可手动标记已学会。听力包括教材原声 MP3、对话练习、AI 单句听力和对话听力；口语直接进入 AI 练习，支持录音／拼写，默认录音并记住选择。口语拼写按中文目标写日语，同样支持回车提交与可选自动下一题。
- 片假名有 104 项内置假名练习，以及不受教材限制的随机单词 AI 练习。输入对应平假名或片假名，回车提交，长音保留「ー」；AI 单词答对后显示中文释义。
- 单词按已掌握词数计算进度，可手动勾选或累计答对 2 道不同 AI 题；听力、口语按达标题数 / 100 计算，同题不重复计数。四模块进度条显示百分比和完成数；课程地图按四项平均值显示灰、铜、银、金、钻石卡片及等级图标。
- 提供中文／日本語界面、侧栏折叠、大字和沉浸模式；播放器支持 0.75×、1×、1.25×。

## 配置与数据

在设置中配置已有的 DeepSeek 出题密钥、MiniMax 朗读配置及北京百炼听音密钥。首次进入未开始的 AI 练习不自动出题；点击开始后会后台准备最多 5 道待答题，并在消耗后补齐。出题、补题、评估及云朗读会调用所配置的服务。单句听力与单词录音先识别再判定，口语直接按原音评分：意思 40、语法 30、发音 30；无法可靠判断发音时不显示该项及总分。

口语拼写只使用 DeepSeek，评分为意思 40、语法 30，共 70 分，不评估发音；达到 56 分且使用目标语法可触发已开启的自动下一题，模块进度要求超过 63/70。录音计入模块进度要求超过 90/100。文字回答和评分可刷新恢复，重答达标后可以计入，但同题最多计一次。

课程 AI 出题重复、格式不完整或服务暂时不可用时，页面自动追加最多 3 次重试，间隔 1、2、4 秒；复用同一请求编号，旧题、答案与反馈在新题成功前保留。可点「停止出题」取消等待，离开练习也会取消；密钥未配置或认证失败不自动重试。自动重试可能产生额外服务用量，达到上限后保留错误与手动重试入口。

学习成绩和配置保存在本机 `data/`，服务器部署时保存在服务器的数据目录。学习备份使用 v4，兼容导入 v1～v3；备份不包含密钥和音频。旧模块的文字记录保留用于兼容与已练课程判定。

听音服务端等待上限为 90 秒，客户端为 135 秒，录音上限仍为 30 秒。录音只在当前页面内存中保留，用于本题回听和失败重试。换题、离开或刷新后释放。升级启动会清理应用管理的历史录音、临时音频及录音关联；外部已有备份不自动清理。云朗读缓存不是练习录音，仍可在设置管理。

单词列表、语法、内置假名练习可离线使用；AI 与云语音需要网络、对应密钥及服务额度。教材原声使用出版社提供的第二版 MP3。AI 反馈为练习参考，真实效果与耗时受网络和服务影响；主要固定界面提供双语，部分动态服务错误仍可能显示中文。

## 发布与维护

```powershell
npm.cmd run build
npm.cmd test
npm.cmd run test:e2e
npm.cmd run package:web
```

源码发布包位于 `releases/nihongo-web.tar.gz`，同时生成带版本号的存档及 SHA-256 文件；不含数据库、密钥、录音、模型或 node_modules。服务器构建时需联网安装依赖。标准服务器升级采用 [v1.4.0 更新流程](docs/v1.4.0-release.md)，共存部署另见 [共存部署说明](docs/deployment-shared.md)。

启动日志为 `data/server.log` 和 `data/server-error.log`。若显示“没有这个接口”，先确认后台已随源码更新重启，仅刷新网页不能加载新增后端接口。

技术栈：React、TypeScript、Vite、Fastify、SQLite。默认仅监听本机；服务器模式经 HTTPS 网关访问，由应用验证持久登录会话，新正式版本发布后需重新验证。个人共享一份学习记录，不提供多人独立账号。仓库与提交约定见 [版本管理](docs/version-control.md)。
