# 第二版语法覆盖核对

本次核对范围为《大家的日语》第二版初级Ⅰ、Ⅱ，第 1—50 课。来源为[出版社公开学习项目表](https://www.3anet.co.jp/np/resrcs/240000/)、[Langoal 分课教案](https://langoal.com/minnano-nihongo-teaching-plan/overview.html)、[日本語教師のN1et 分课教案](https://jn1et.com/kyouan1/)，以及用户提供的第 32 课文法照片。各课的主句型、相关助词、副词、活用和已核对的补充用法分别列入核对表。

共 250 个核对项目，对应 211 张语法卡；相关用法可共用一张卡。新增 46 张卡，每张有中文讲解、结构和两句原创例句，并追加提取任务。旧卡 ID、旧提取任务、词条、课次归属、对话与历史映射保持原样。所有内容变更均在 `src/content/`，没有数据库迁移或学习记录写入。

第 32 课完整覆盖照片的六个标题：建议、でしょう推测、かもしれません可能性、ましょう主动承担、数量词で的期限／限度、不特定事物的修饰语序。另在原卡中补充肯定／否定接续、去だ、建议语气和きっと／たぶん／もしかしたら。

`src/content/grammar-coverage.ts` 是独立核对清单，显式记录各课项目与语法卡的对应关系；`tests/grammar-coverage.test.ts` 检查引用、原创例句、提取任务、第 32 课六项及旧数据映射。不能用“每课至少三项”替代此清单。

公开学习项目表和教案不是完整的中文《翻译·文法解说》逐页影印件。本次覆盖保证以明确列出的核对项目和第 32 课照片为边界；未取得完整中文文法原件，不能声称已完成该书所有细注的逐页零遗漏认证。补充发现应按原课归属追加，禁止重排已有 ID。

验证使用临时 SQLite 和模拟 AI 服务，不接入真实学习库或调用付费模型。AI 新题的情境与历史去重有自动检查；自然程度仍需结合实际模型输出观察。根据用户补充的 iPhone／iPad Safari 信息，录音增加了触摸不强制焦点、后台停止及停止与取消共用幂等保护；WAV 解码改用离线上下文，避免为格式转换打开实时音频输出。保留原有编码格式选择顺序。验证除模拟麦克风交互外，还包括真实 48 kHz 双声道重采样、30 秒截断，以及合成 WebM／Opus 音频的实际录制与离线转换。桌面 WebKit 测试不等同于 iOS 真机验证，尚未在用户出现闪白的原设备上复现。
