# v1.11.0：练习可靠性与影子跟读

课程内听力、口语的段位与课程地图共用听力／口语百分比平均值及段位规则；每项以 100 题为分母并封顶 100%。专项与综合练习继续按无限累计题数计段位，不改变历史记录。

出题及独立范围审核共用 65 秒总期限。审核使用确定性参数，允许通过结果省略非必要解释；仍校验本课范围、句子合理性及永久精确去重。减少狭窄单元内正常短句的相似误判。题池会恢复最多五道未答且未跳过的已有题，临时失败按退避间隔自动补充，重新联网可恢复；不会把后台准备直接记作学习进度。

真实供应商验收发现返回题目可能夹带输入教学元数据，以及重试缺少原稿导致重复犯错。供应商返回先提取题目字段再做严格校验；审核拒绝后携带原稿及具体原因修正，并重新审核。对话审核明确男女轮次、目标语法的具体含义和活动前后顺序。出题只传语法结构与解释，避免教材例句中的其他课词汇与本课白名单产生矛盾；原教材资源不变，综合练习仍保留明确已学例句作为依据。

听音评分兼容无害的返回格式差异。缺少关键字段时用同一录音自动重新听取一次，两次合计仍受 90 秒限制；无效关键分数、伪造引用或无法可靠判断的发音不会被编造补齐。原录音和幂等请求编号保持不变。

口语参考表达新增按住麦克风跟读，浏览器的日语实时识别结果与参考句匹配后高亮。支持上滑取消、空格／回车按住、松手完成；折叠参考、切题和播放其他音频会停止识别。高亮代表识别文字匹配，不是发音评分。保留常规播放器；浏览器不支持实时识别时明确提示。手机布局和浏览器事件已验证，真实 iPhone 的麦克风识别尚未实机验证。

新增错误诊断仅记录错误代码、阶段、状态和耗时，不记录录音、题目、密钥或原始模型返回。无数据库结构变更。
