# 音频播放迭代（v1.1.2）

在本机打开应用，进入「听懂 → 教材原声」，播放任意一条音轨即可试用。

## 操作变化

1. 对应音频旁增加「快退 2 秒」「快进 2 秒」和播放时间。暂停时跳转仍保持暂停，跳转不会越过开头或结尾。
2. 空格暂停／继续当前声音；播放结束后可用空格重播。点播放入口后仍可直接按空格。长按只处理一次，不会连续切换。
3. 输入框、选择框、输入法组合输入和录音按钮保留原有键盘操作；其他普通按钮不被播放器抢占。
4. 教材原声加载或缓冲时显示实际状态；等待过久或加载失败时提供「重试播放」，尽量保留失败前的位置。切到后台时暂停并保留进度，回来后手动继续。

快退／快进覆盖教材 MP3、自己的录音和 MiniMax 合成音频；多句合成朗读跳转当前句，后续句子仍按顺序播放。系统中文／日语朗读使用 SpeechSynthesis，没有按秒定位能力，因此禁用这两个按钮并显示说明，仍支持暂停、继续和从头播放。音频时长尚未读取时也暂时禁用跳转。

## 教材原声排查

用户反馈来源是「听懂 → 教材原声 MP3」。2026-09-30 抽查两册第 1、26、50 课的第一条官方音轨：

- 出版社链接返回正常，支持 Range 请求（206）；实际播放器通过 `Audio.src` 直接播放，没有跨域 fetch、代理或打包教材文件。
- 真实 Edge 无界面浏览器使用应用的播放器和教材组件，首次进入播放约 509／495／435 ms；每条创建一个播放器并发出一次 206 请求。
- 暂停后前后跳转 2 秒、继续、空格操作通过；未观察到媒体错误或持续缓冲。
- 原实现没有跟踪 waiting、stalled、playing 等事件，缓冲时可能错误显示正在播放；页面隐藏时直接停止并清空了播放进度。本次修正了这些可确认的问题。

本次未复现用户网络环境下的断续或无声，不能据此认定所有原因已经消除。未验证真实设备扬声器的可听音质、手机后台调度或阿里云网站上的播放效果。后台行为通过真实监听器加模拟可见性事件验证。
