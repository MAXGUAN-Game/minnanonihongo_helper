### 现有服务器的完整更新步骤

目标为 `8.133.242.232`，运行目录 `/opt/nihongo`。现有网站用户名、密码、域名／IP HTTPS 和 AI 密钥自动沿用，无需重新运行 `deploy/configure.mjs`。

1. 从 [GitHub v1.4.0 发布页](https://github.com/MAXGUAN-Game/minnanonihongo_helper/releases/tag/v1.4.0) 下载 `nihongo-web-v1.4.0.tar.gz` 和 `nihongo-web-v1.4.0.tar.gz.sha256`，或使用本机 `C:\LanguageMaster\releases` 中的同名文件。通过服务器面板上传两个文件到 `/tmp`。
2. 在服务器终端整段执行以下命令。构建期间原网站继续运行；切换和验证时会短暂暂停访问。使用独立源码目录，不把压缩包解压到运行目录。

```bash
(
set -e
cd /tmp
sha256sum -c nihongo-web-v1.4.0.tar.gz.sha256
release_src=$(sudo mktemp -d /opt/nihongo-v140-src-XXXXXXXX)
sudo tar -xzf /tmp/nihongo-web-v1.4.0.tar.gz -C "$release_src"
sudo systemd-run --unit="nihongo-update-v140-$(date +%s)" --collect \
  --service-type=exec --property=UMask=0077 \
  --property=TimeoutStopSec=300 \
  --property=StandardOutput=append:/opt/nihongo/update-v1.4.0.log \
  --property=StandardError=inherit \
  /usr/bin/bash "$release_src/deploy/update-session-release.sh" /opt/nihongo
)
```

3. 查看日志：`sudo tail -n 50 -f /opt/nihongo/update-v1.4.0.log`。本次 `UPDATE_START v1.4.0` 后出现 `AUTH_VERIFIED v1.4.0`、`UPDATE_OK v1.4.0` 才算完成，随后 Ctrl+C 退出日志。只有 `Running as unit...` 不代表更新成功。若失败，保留日志和备份，勿手动导入旧学习快照。
4. 检查版本：

```bash
sudo docker compose --project-directory /opt/nihongo -f /opt/nihongo/compose.yaml \
  exec -T app node -p 'require("./package.json").version'
```

应输出 `1.4.0`。打开原网站，Ctrl+F5 刷新，用原用户名和密码登录；检查已有进度、点击单词详情和手动掌握。此后刷新及关闭浏览器重开均保持登录，直到下一次正式版本更新。
