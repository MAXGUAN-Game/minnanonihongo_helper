# v1.1.1：录音入口居中，播放控制跟随语音

## 改了什么

1. “自己说”合并为一个居中的麦克风按钮。点击开始、再点结束；也能按住说话，松开结束。保留空格、回车、30 秒限制和“卡住了，给我提示”。
2. 播放控制放在对应的 AI 消息、录音、教材音轨或例句旁。支持暂停、继续、从头播放和停止，移除底部全局播放栏。
3. 自动朗读、慢速听和回放共用同一音源位置；切换到另一句时，控制跟随切换。原文仍默认隐藏。

本版是界面与播放交互更新，不修改数据库结构。网站仍使用原来的登录、HTTPS、API 设置和学习数据。

## 更新服务器

在阿里云服务器终端执行。运行目录仍是 `/opt/nihongo`；源码目录是 `/opt/nihongo-src`。

### 1. 下载并后台构建

```bash
(
set -e
sudo git -C /opt/nihongo-src fetch origin tag v1.1.1
if [ -n "$(sudo git -C /opt/nihongo-src status --porcelain)" ]; then
  echo "Source directory has local changes. Stop and review them first."
  exit 1
fi
sudo git -C /opt/nihongo-src checkout --detach v1.1.1
sudo systemd-run --unit=nihongo-build-v111 --collect \
  --service-type=exec --working-directory=/opt/nihongo-src \
  --property=StandardOutput=append:/opt/nihongo/build-v1.1.1.log \
  --property=StandardError=inherit --property=UMask=0077 \
  /usr/bin/docker build --progress=plain --pull=false \
  -t nihongo-web:v1.1.1 .
)
```

构建期间网站继续运行。查看进度：

```bash
sudo tail -n 30 /opt/nihongo/build-v1.1.1.log
```

看到 `naming to docker.io/library/nihongo-web:v1.1.1`、`unpacking ... done` 和最终 `DONE` 后，进行下一步。

### 2. 备份并切换

执行期间保持终端打开，网站会短暂停止。命令会保留当前运行镜像和完整数据备份。

```bash
sudo bash <<'BASH'
set -euo pipefail
umask 077
cd /opt/nihongo
compose() { docker compose -p nihongo-web -f compose.yaml "$@"; }

docker image inspect nihongo-web:v1.1.1 >/dev/null
for item in server-data .env compose.yaml deploy/Caddyfile; do
  test -e "$item" || { echo "Missing: $item"; exit 1; }
done
app_id=$(compose ps -q app)
test -n "$app_id"
old_image=$(docker inspect --format '{{.Image}}' "$app_id")

backup_dir=$(mktemp -d /opt/nihongo-backup-v111-XXXXXXXX)
printf 'Backup directory: %s\n' "$backup_dir"
printf '%s\n' "$old_image" > "$backup_dir/old-image.txt"
docker tag "$old_image" "nihongo-web:rollback-${backup_dir##*-}"

trap 'compose start app >/dev/null 2>&1 || true' EXIT
compose stop app
tar -czf "$backup_dir/data-and-config.tar.gz" \
  server-data .env compose.yaml deploy/Caddyfile
echo "Backup completed."

docker tag nihongo-web:v1.1.1 nihongo-web:local
trap - EXIT
compose up -d --no-build --pull never --no-deps \
  --wait --wait-timeout 120 app
compose ps
compose exec -T app node -p 'require("./package.json").version'
BASH
```

看到 `healthy` 和 `1.1.1` 后，打开原网址并刷新。电脑可按 `Ctrl + F5`；手机重新加载页面。

## 回退到刚才的版本

本次没有数据库结构变更，通常只需恢复旧镜像，学习数据继续保留。将下面第一行的路径替换为更新命令打印的完整备份目录：

```bash
(
set -e
backup_dir=/opt/nihongo-backup-v111-替换为实际后缀
old_image=$(sudo cat "$backup_dir/old-image.txt")
sudo docker image inspect "$old_image" >/dev/null
sudo docker tag "$old_image" nihongo-web:local
cd /opt/nihongo
sudo docker compose -p nihongo-web -f compose.yaml up -d \
  --no-build --pull never --no-deps --wait --wait-timeout 120 app
sudo docker compose -p nihongo-web -f compose.yaml exec -T app \
  node -p 'require("./package.json").version'
)
```

数据备份留作恢复用途；恢复旧数据会丢失备份之后的新记录，不在正常界面回退时覆盖它。继续使用服务器现有的 Compose、Caddyfile 和 `.env`。
