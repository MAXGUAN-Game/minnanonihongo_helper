# v1.4.4 接入已通过试听的 Haruka

用户确认 MiniMax 的整句假名、发音词典候选仍有错误断句，而 Microsoft Haruka 读取「明日の会議は午後2時40分からです。」正常。本版在网页明确选择设备上已安装的日语 Haruka，默认优先于既有 MiniMax 配置。没有改动服务器保存的声音设置或密钥。

句子保留完整原文，将有效时刻中的汉字数字转为阿拉伯数字，不拆分音频。单词使用词库假名；重播、慢速和自动朗读通过统一播放器。男女对话使用 Ichiro、Haruka；缺少 Ichiro 时提示，不用同一女声假装男女对话。Haruka 路径以自然 1× 起播，播放控件仍支持变速，设置中可关闭本设备偏好。

此修复适用于安装了 Haruka 的 Windows 设备。没有 Haruka 的其他设备继续使用原有声音配置，设置中显示此限制。没有声称修好了 MiniMax 服务自身的日语韵律；未通过听音验收的 v1.4.3 词典候选已撤回，不发布该方案。

验证：137 项相关测试、类型检查和构建通过；真实 Edge 浏览器用实际安装的 Microsoft Haruka 完整播放两个问题句子，均触发开始与结束事件，无错误、无 MiniMax 或声音设置网络请求。检查记录位于本机 `test-results/haruka-live-check.json`，不进入发布包。
