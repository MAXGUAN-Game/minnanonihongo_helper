## 更新现有服务器

目标：`8.133.242.232`，运行目录：`/opt/nihongo`。将本机 `releases/nihongo-web-v1.4.2.tar.gz` 和同名 `.sha256` 文件上传到服务器 `/tmp`，在阿里云终端执行：

```bash
(
set -e
cd /tmp
sha256sum -c nihongo-web-v1.4.2.tar.gz.sha256
release_src=$(sudo mktemp -d /opt/nihongo-v142-src-XXXXXXXX)
sudo tar -xzf nihongo-web-v1.4.2.tar.gz -C "$release_src"
sudo systemd-run --unit="nihongo-update-v142-$(date +%s)" --collect \
  --service-type=exec --property=UMask=0077 \
  --property=TimeoutStopSec=300 \
  --property=StandardOutput=append:/opt/nihongo/update-v1.4.2.log \
  --property=StandardError=inherit \
  /usr/bin/bash "$release_src/deploy/update-session-release.sh" /opt/nihongo
)
```

查看日志：`sudo tail -n 60 -f /opt/nihongo/update-v1.4.2.log`。本次更新出现 `AUTH_VERIFIED v1.4.2` 和 `UPDATE_OK v1.4.2` 才表示脚本完成。随后刷新页面、使用原有账号登录，确认历史进度并试听问题句子。
