发布日期：2026-10-24。本次交付为本地源码部署包，远程服务器须执行下方更新命令。

## 本次更新

- 火箭图标与新名称；左侧保留 50 课地图、片假名、设置，支持折叠。课程改为单词、语法、听力、口语四模块，移除用起来、复习入口及口语原创练习入口。
- 单词列表覆盖 50 课，共 2,258 个词与固定表达；默认隐藏中文，支持逐词或全部显示。按后续计划调整，取消五个内置例句及弹窗，已删除原有六课的相关例句。词库来源、数量和差异见 [核对记录](v1.3.0-vocabulary-audit.md)。
- 单词 AI 造句和单句听力均可选择拼写／录音；拼写按回车提交，正确自动下一题并保持焦点。Shift+Enter 换行，输入法组合输入时不提交。
- 片假名内置 104 项循环练习；AI 单词模式每批生成 10 词，输入正确平假名后自动前进，长音保留「ー」。第一次进入不自动调用出题服务。
- 四模块学习进度充能条；中文／日本語切换、沉浸模式、侧栏折叠及回答方式保存在浏览器。沉浸模式隐藏品牌、目录、课程大标题及多余文字，保留作答与图标操作。
- 听力依次为教材原声 MP3、对话练习、AI 练习。统一图标播放器提供播放／暂停、前后 2 秒、重播、停止和 0.75×／1×／1.25×；云音频切速不重新合成。AI 对话继续使用 A 男／B 女交替声音。
- 题目优先使用本课词汇，并补充实际练过课程的词汇；语法仍按本课 70%、上课 20%、上上课 10% 抽取，第 1、2 课使用特例。提示词约束不代表绝对不超纲。

## 数据与评分

单词进度为独立答对的词汇覆盖率，语法进度为标记学会的语法覆盖率。听力、口语按实际语法课统计，每题只取首次有效独立答案，各分项取最近 100 题。平滑分数为 `round(100 × (1 + Σx) / (2 + 有效题数))`：听力正确取 1、错误取 0；口语取意思与语法分之和除以 70。

无样本显示「—」，少于 10 题标为暂估。听力充能条可显示已练分项的暂估平均；正式听力总分需两类各满 10 题，听说综合值需三个分项各满 10 题。口语单题继续保留意思 40、语法 30、发音 30；发音未知不作为零分。

学习备份升级为 v4，兼容导入 v1～v3，保留题目、文字反馈和成绩，丢弃录音链接。新程序启动会清理应用管理的旧录音、临时音频和录音元数据。新录音只留在当前页面内存，换题、离开或刷新后释放。密钥和音频不进入学习备份；外部已有备份不自动清理。

## 更新已有服务器

兼容已安装 1.1.0、1.1.1、1.1.2、1.2.0 和 1.3.0 的标准 `/opt/nihongo` 部署。脚本会核对镜像、数据挂载及网关；共存部署配置不同，应按其部署方式单独处理。

在电脑 PowerShell 上传源码包与校验文件：

```powershell
scp "C:\LanguageMaster\releases\nihongo-web-v1.3.0.tar.gz" "C:\LanguageMaster\releases\nihongo-web-v1.3.0.tar.gz.sha256" admin@8.133.242.232:/tmp/
```

在服务器执行：

```bash
(
set -e
cd /tmp
sha256sum -c nihongo-web-v1.3.0.tar.gz.sha256
src=$(sudo mktemp -d /opt/nihongo-v130-src-XXXXXXXX)
sudo tar -xzf /tmp/nihongo-web-v1.3.0.tar.gz -C "$src"
sudo test -f "$src/src/server/katakana-practice.ts"
sudo systemd-run --unit=nihongo-update-v130 --collect \
  --service-type=exec --property=UMask=0077 \
  --property=TimeoutStopSec=300 \
  --property=StandardOutput=append:/opt/nihongo/update-v1.3.0.log \
  --property=StandardError=inherit \
  /usr/bin/bash "$src/deploy/update-release.sh" /opt/nihongo
)
```

脚本先构建镜像，再停应用写入并备份数据库、登录配置和网关配置；备份排除历史录音和临时录音目录，目录前缀为 `nihongo-backup-v130-`。失败时恢复兼容的数据库快照与旧镜像，避免把旧程序放在迁移后的数据库上运行。原网关保持运行。若日志出现 `ROLLBACK_FAILED`，保留备份目录并检查错误，不要仅手动切换旧镜像。

```bash
sudo tail -n 40 /opt/nihongo/update-v1.3.0.log
cd /opt/nihongo
sudo docker compose -p nihongo-web -f compose.yaml exec -T app node -p 'require("./package.json").version'
```

确认本次日志出现 `UPDATE_OK v1.3.0`，且容器版本为 `1.3.0` 后刷新浏览器。验证片假名 AI 出题、单词列表、单句听力拼写／录音、口语评分和旧成绩恢复。若仍提示“没有这个接口”，检查容器版本；刷新前端不能代替重启后台。
