# AI 直接听录音点评

v1.2.0 新增的「自己说 → AI练习」使用同一百炼设置，额外返回意思40、语法30、发音30的AI练习参考分；发音无法可靠判断时不显示该项和总分。下面描述的定性反馈仍用于「原创练习」。无限出题、听写及升级步骤见 [v1.2.0说明](v1.2.0-release.md)。

口语练习录音结束后，把录音音频交给阿里云百炼 Qwen3.8-Omni-Flash，一次返回简短的语法与读音反馈。评估不需要本地 Whisper 程序或模型，也不等待先转成文字。结果中的“AI 听到的内容”是参考信息，用户不需要确认转写才能获得点评。

## 配置

1. 在阿里云百炼开通 **华北2（北京）** 的 `qwen3.8-omni-flash` 模型访问权限，创建同地域的 API Key。
2. 在网页“学习设置”的 AI 听音设置中保存该密钥。DeepSeek 的文字对话密钥不能用作百炼密钥。
3. 业务空间 ID 可留空，此时使用 `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions`。填写北京地域的业务空间 ID 后，使用 `https://<业务空间ID>.cn-beijing.maas.aliyuncs.com/compatible-mode/v1/chat/completions`。只接受字母、数字和连字符，不接受网址。
4. 回到口语练习，录一句简短日语。录音会发送到百炼模型服务进行分析，调用使用该账号的额度。不要在问题截图、聊天消息或日志里贴密钥。

百炼官方目前推荐业务空间专属域名，并明确旧 `dashscope.aliyuncs.com` 域名仍然可用。模型和密钥需要属于相同地域。[官方 Chat API 与服务地址](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions)

## 接入方式与速度

服务端向 `/chat/completions` 发起一次请求，使用 WAV 音频的 Base64 Data URL 作为 `input_audio`，同时提供当前口语任务和本课语法的精简信息。请求不包含此前确认过的转写或完整对话历史。

固定使用 `qwen3.8-omni-flash`，设置 `reasoning_effort: "none"` 关闭深度思考，`modalities: ["text"]` 只输出文字，`stream: false` 一次返回短结果。Qwen3.8 支持日语音频输入；旧 Qwen3/3.5 Omni 的强制流式约束不能直接套用到新型号，也不要改成仅支持中英音频的旧 `qwen-omni-turbo`。[官方模型、输入示例与思考控制](https://help.aliyun.com/zh/model-studio/qwen-omni)

使用 `response_format: {"type":"json_object"}` 并在提示词中指定 JSON。服务端再严格校验字段，拒绝截断结果、额外分数字段或不属于本课的语法 ID。音频等多模态输入不支持严格 JSON Schema；JSON Object 模式不能代替本地校验。[官方结构化输出说明](https://help.aliyun.com/zh/model-studio/qwen-structured-output)

请求与读取完整响应共用 **25 秒**上限，反馈最多两项改进，自动重试次数为零。超时会停止本地等待并发出取消请求，录音仍可手动重试；取消不能保证云端尚未开始计费。25 秒是等待上限，不是承诺每次请求的耗时。实际延迟取决于录音长度、网络和服务负载，需用部署后的真实录音测量。

## 反馈边界

- 语法点评依据实际听到的表达，接受不同于范句的合理答案。
- 读音点评依据原始声音，只指出有把握听出的读音或节奏问题；不能根据转写猜测发音。发音判断不确定时明确提示，整体听不清时建议重录。
- 反馈是 AI 的学习建议，没有经过考试评分校准，不生成“发音 92 分”等精确分数，也不承诺日语音素和高低音调的专业测量精度。

不能直接用常见中英文评测 API 代替：讯飞流式语音评测和腾讯新版口语评测的官方语种范围均为中文与英文，语音识别支持日语并不意味着同一厂商的发音评测也支持日语。[讯飞官方语种](https://www.xfyun.cn/doc/Ise/IseAPI.html)、[腾讯新版评测官方语种](https://cloud.tencent.cn/document/product/1774/107497)

## 出错时

| 提示 | 处理 |
| --- | --- |
| 未配置百炼密钥 | 在 AI 听音设置保存北京地域的百炼密钥 |
| 密钥未被接受 | 核对密钥是否有效、是否属于北京地域，再重试 |
| 无模型权限或模型不可用 | 在百炼检查模型开通状态、业务空间权限与地域 |
| 服务繁忙或额度不足 | 检查百炼额度，稍后重试 |
| 超过 25 秒 | 保留当前录音重试；短句也经常超时则检查服务器到百炼的网络 |
| 没听清或没有有效音频 | 靠近麦克风，重录一句清楚的日语 |
| 反馈不完整 | 重试点评；不会把不完整结果保存为成功反馈 |

服务端错误不会透传供应商响应正文或密钥，响应正文读取限制为 64 KiB。实现测试通过模拟 API 验证原始音频确实进入请求，以及超时、权限、限流、截断和错误结果边界；这不等于已完成付费模型的实际效果或延迟验证。
