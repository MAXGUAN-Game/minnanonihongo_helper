# v1.4.7：输入时仍可控制播放器

F1–F4 和 Esc 在输入框、文本域、选择框和可编辑区域内仍控制当前播放器，不改变输入内容和焦点。输入法组合期间也可使用这些播放器按键；空格保留输入和表单控件原有行为。

播放器功能键在 window 捕获阶段处理，同时取消默认行为并阻止其他页面处理器重复执行。F1–F4 在没有活动音频时仍取消浏览器默认动作；Esc 在没有活动音频时保留关闭弹窗等行为。带 Ctrl、Alt、Meta、Shift 的组合不作为播放器快捷键。

优先级适用于浏览器发送给网页的键盘事件，无法覆盖操作系统或浏览器保留且不传入页面的快捷键。

验证包括真实浏览器按键、输入内容及焦点保留、与输入框捕获处理器冲突、默认行为取消、输入法、空格输入和长按。无数据库变更。
