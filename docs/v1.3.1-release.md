# v1.3.1：口语拼写与练习交互调整

最新发布及服务器更新命令见 [v1.3.2 发布说明](v1.3.2-release.md)。本页保留 v1.3.1 的历史说明。

本次交付为本地源码部署包；远程服务器需按下方步骤上传更新。原 v1.3.0 版本存档保留。

## 修改内容

- 所有拼写练习（普通假名、片假名 AI、单词造句、单句听力、口语拼写）支持答对后再按一次回车进入下一题，无需开启自动下一题。第二次回车不重复评分或累计完成数；修改已评分的答案后须重新提交，输入法确认键和长按回车不触发跳题。自动下一题开关继续保留。
- 片假名 AI 练习从各领域真实片假名单词中随机出题，不受教材、单元、已学词汇或初学者范围限制；每批随机选词并避免最近重复。假名练习和 AI 单词练习均接受对应的平假名或片假名输入。
- 片假名的「假名练习」和「AI练习」均需按回车提交，输入法确认键不提交。默认停留当前题；勾选「回车答对自动下一题」后才自动换题，也可手动点击「下一题」。两页共用并记住开关状态，同一道题只累计一次完成数。AI 单词题答对后显示中文释义。
- 单词造句、单句听力、对话听力、口语及片假名 AI 练习在首题生成后，后台预先准备最多 5 道待答题（不含当前题）。下一题优先取缓存，消耗后立即异步补齐；后台准备期间可继续作答，失败时保留当前题并提供重试。切换课程、题型或离开时停止该页面的补题，后台生成不改变服务器记录的当前题。激活缓存单词题前再次检查掌握状态。
- AI 分析完成后，参考表达默认展开，并标注考点及其来源单元；单词练习显示目标单词，对话听力的原文也默认展开。
- 单元单词进度改为「已掌握单词数 / 本单元单词总数」。单词表可勾选已掌握；同一个词累计答对 3 道不同的 AI 练习也会自动掌握。已掌握单词不再出题；取消勾选会重新累计，历史答案保留。全部掌握后显示完成提示。手动标记保存到服务器并随备份导出，旧备份仍可导入。
- 听力、口语进度分别按本单元完成的达标题数 / 100 计算，进度条同时显示百分比及已完成 / 总数。单句听力、会话听力每道正确题各算 1 题；录音口语须超过 90/100，拼写口语按 70 分满分换算，须超过 63/70。重答达标可以计入，但同一道题最多计 1 次，最多显示 100/100。题数计入当前练习单元，参考表达另行标注语法来源单元。
- 单词造句、单句听力和口语拼写：回车默认只提交。在检查按钮右侧打开「回车答对自动下一题」后，回车作答达标才自动前进；点击检查按钮仍停留本题。开关在浏览器记住，评分途中关闭也能阻止自动换题。Shift+Enter 换行，输入法组合输入不提交。
- 课程 AI 出题重复、格式不完整、服务暂时不可用或服务端超时时，自动追加最多 3 次请求，间隔 1、2、4 秒。重试复用同一请求编号，当前题、文字答案和反馈在新题成功前保留。可点「停止出题」，离开练习也会取消等待。缺少密钥或认证失败不自动重试；达到上限后显示错误并保留手动重试入口。自动重试可能增加 AI 服务用量。
- 口语新增「录音／拼写」回答模式，默认录音并记住选择。拼写通过 DeepSeek 评估意思 40 分、语法 30 分，共 70 分，不提供发音分；合计至少 56 分且使用目标语法仍可触发已开启的回车自动换题，单元进度采用上面的超过 90% 规则。录音继续使用原音评分。
- 口语文字草稿在切换输入方式时保留，提交后的答案和评分可刷新恢复。文字不增加发音样本。录音或评分进行中禁止切换输入方式。
- 修复课程首次加载较慢时的键盘焦点：课程加载完成后再聚焦标题。

## 直接上传服务器更新

适用于现有 `/opt/nihongo` 标准部署，支持从 1.1.0、1.1.1、1.1.2、1.2.0、1.3.0 或 1.3.1 更新。共存部署配置不同，不使用此脚本直接覆盖。

1. 在电脑文件资源管理器打开 `C:\LanguageMaster\releases`。通过服务器面板的文件管理，将以下两个文件上传到服务器 **`/tmp`**，保留文件名，不用手动解压：

   ```text
   nihongo-web-v1.3.1.tar.gz
   nihongo-web-v1.3.1.tar.gz.sha256
   ```

2. 打开服务器终端，整段复制执行：

   ```bash
   (
   set -e
   cd /tmp
   sha256sum -c nihongo-web-v1.3.1.tar.gz.sha256
   src=$(sudo mktemp -d /opt/nihongo-v131-src-XXXXXXXX)
   sudo tar -xzf /tmp/nihongo-web-v1.3.1.tar.gz -C "$src"
   sudo test -f "$src/src/server/ai-practice.ts"
   sudo systemd-run --unit=nihongo-update-v131 --collect \
     --service-type=exec --property=UMask=0077 \
     --property=TimeoutStopSec=300 \
     --property=StandardOutput=append:/opt/nihongo/update-v1.3.1.log \
     --property=StandardError=inherit \
     /usr/bin/bash "$src/deploy/update-release.sh" /opt/nihongo
   )
   ```

   出现 `Running as unit...` 表示后台更新已开始，并不表示完成。预计构建 5～20 分钟，取决于服务器网络。

3. 查看日志：

   ```bash
   sudo tail -n 40 -f /opt/nihongo/update-v1.3.1.log
   ```

   等本次日志出现 **`UPDATE_OK v1.3.1`**，按 Ctrl+C 退出日志查看。如果出现 `UPDATE_FAILED` 或 `ROLLBACK_FAILED`，保留错误输出与备份目录，不要反复启动更新。

4. 确认实际容器版本：

   ```bash
   cd /opt/nihongo
   sudo docker compose -p nihongo-web -f compose.yaml exec -T app node -p 'require("./package.json").version'
   ```

   必须输出 **`1.3.1`**。只刷新页面无法加载新的口语文字评分接口。

5. 回到网站按 Ctrl+F5。进入「口语 → 回答模式 → 拼写」，提交一句日语，确认显示文字表达评分；检查默认回车停留本题，打开开关后达标自动换题。

## 数据与回滚

脚本先构建，再停应用写入、备份成绩数据库及登录／网关配置。备份目录前缀为 `nihongo-backup-v131-`；排除录音存档与临时录音目录。失败时同时恢复兼容数据库快照与旧镜像。原登录配置、网关、学习成绩和密钥保留。

录音仍不存档；从旧版首次升级时，应用会清理其管理的历史录音和录音关联，外部已有备份不自动清理。学习备份仍为 v4，支持导入 v1～v3 及既有 v4；新增口语文字成绩需要本版读取，旧版可能无法导入包含这类记录的新备份。不要只切换旧镜像而继续使用新版写入的数据库。
