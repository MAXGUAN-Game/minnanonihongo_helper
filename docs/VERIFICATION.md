## 复现命令

```powershell
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
npm.cmd run test:e2e
node --import tsx scripts/check-grammar-chat.mjs
```

自由聊的真实接口复测需要已配置 DeepSeek，且会消耗少量账户额度；仅显式执行以下命令才会调用，普通测试不运行它：

```powershell
node --use-env-proxy --import tsx scripts/check-grammar-chat-live.mjs --allow-paid
```

语音链复现需要先安装本机语音组件和 Windows 日文声音。先在服务运行时生成合成录音，再运行使用临时数据库的浏览器语音测试：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check-speech.ps1
node --import tsx scripts/check-local-speech.mjs
```

合成录音位于 `test-results/japanese-speech-sample.wav`，由 `scripts/check-speech.ps1` 生成。
