# v1.2.0：无限 AI 听力与口语练习

「听懂」新增 AI 练习：单句听写、对话听力。「自己说」新增 AI 练习：中文目标转日语录音，直接听原音评分。下一题按钮在题卡上方，每次点击才生成，首次进入不会自动产生出题用量。

## 使用

继续使用学习设置中已有的 DeepSeek 出题密钥、MiniMax 朗读配置与北京百炼听音密钥。缺少某项配置时，页面会提示对应设置；不会用固定练习冒充 AI 新题。

- 单句听写：完整写出听到的日语，合理汉字／假名写法均可；提交后显示原句、假名、中文及反馈。漏词、助词、时态或词序变化仍需修改。
- 对话听力：4～6句双人日语对话，一道中文四选一；提交后查看反馈和对话原文。支持重听、慢速和音频缓存。
- AI对话人物固定为A（男）先说、B（女）接话，严格交替；问题与解释中的性别指代遵守此顺序。整段、慢速和原文逐句播放统一使用A的温和管家男声、B的亲切女士女声，保留速度与缓存设置。AI对话需要启用MiniMax云语音；失败后可重试播放，不改用无法保证性别的系统声音。单句和原创练习继续沿用原有音色配置。
- AI口语：意思40分、语法30分、发音30分。总分在服务器计算；发音不确定时不显示该项和总分。不同于原创口语的定性点评，这里是 AI 练习参考分。看过反馈再重练标记为借助提示。

主考语法按每题独立抽取：本课70%、上课20%、上上课10%；第1课100%本课，第2课80%本课／20%前课。少量题不保证严格配额。第26课回看第25、24课。

题目及反馈保存在服务器，跨刷新恢复；完全重复跨历史排除，近期200道同类题做近似检查。相同语法可以持续练习；近似去重基于文字，不保证所有语义永远互不相似。

## 更新已有服务器

在电脑的 PowerShell 上传当前构建的源代码包：

```powershell
scp "C:\LanguageMaster\releases\nihongo-web.tar.gz" admin@8.133.242.232:/tmp/nihongo-web.tar.gz
```

服务器终端执行：

```bash
(
set -e
src=$(sudo mktemp -d /opt/nihongo-v120-src-XXXXXXXX)
sudo tar -xzf /tmp/nihongo-web.tar.gz -C "$src"
sudo test -f "$src/src/server/ai-practice.ts"
sudo systemd-run --unit=nihongo-update-v120 --collect \
  --service-type=exec --property=UMask=0077 \
  --property=TimeoutStopSec=300 \
  --property=StandardOutput=append:/opt/nihongo/update-v1.2.0.log \
  --property=StandardError=inherit \
  /usr/bin/bash "$src/deploy/update-release.sh" /opt/nihongo
)
```

源版本为1.2.0，兼容已安装1.1.0、1.1.1、1.1.2及1.2.0。脚本先构建，再备份现有数据、登录配置和网关配置；失败时恢复原镜像。备份目录以前缀 `nihongo-backup-v120-` 标识。

```bash
sudo tail -n 40 /opt/nihongo/update-v1.2.0.log
cd /opt/nihongo
sudo docker compose -p nihongo-web -f compose.yaml exec -T app node -p 'require("./package.json").version'
```

确认本次日志出现 `UPDATE_OK v1.2.0` 且容器版本为 `1.2.0` 后刷新浏览器。进入「听懂 → AI练习」和「自己说 → AI练习」验证入口；各生成一题，确认朗读、听写和录音评分。实际部署由服务器执行上述命令完成，本地生成安装包不代表远程已更新。

## 数据与验收
