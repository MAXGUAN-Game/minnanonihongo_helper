# v1.1.2：音频跳转、空格控制与播放恢复

打开阿里云服务器的远程终端，执行下面第 1 步。代码会先在后台构建，完成后备份并切换应用。通常预留 5–15 分钟，下载较慢时会更久。

本版包含 v1.1.1 的录音按钮居中、播放器跟随语音，以及新增的快退／快进 2 秒、空格暂停／继续和教材原声缓冲处理。可从已运行的 v1.1.0 或 v1.1.1 直接更新，不修改数据库结构。

## 1. 下载并后台更新

以下命令在 **阿里云服务器** 执行，源码目录仍为 `/opt/nihongo-src`，运行目录仍为 `/opt/nihongo`。

```bash
(
set -e
if sudo systemctl is-active --quiet nihongo-update-v112.service; then
  echo 'Update is already running. Read the log instead.'
  exit 1
fi
sudo git -C /opt/nihongo-src fetch origin tag v1.1.2
changes=$(sudo git -C /opt/nihongo-src status --porcelain)
if [ -n "$changes" ]; then
  echo 'Source directory has local changes. Stop and review them first.'
  exit 1
fi
sudo git -C /opt/nihongo-src checkout --detach v1.1.2
sudo systemd-run --unit=nihongo-update-v112 --collect \
  --service-type=exec --property=UMask=0077 --property=TimeoutStopSec=300 \
  --property=StandardOutput=append:/opt/nihongo/update-v1.1.2.log \
  --property=StandardError=inherit \
  /usr/bin/bash /opt/nihongo-src/deploy/update-release.sh
)
```

看到 `Running as unit: nihongo-update-v112.service` 表示任务已启动，不表示更新完成。此后关闭终端或本地电脑，服务器上的更新任务会继续；阿里云服务器本身需要保持运行。

脚本先构建 `nihongo-web:v1.1.2`，构建成功后才停止应用进行备份与切换。备份与切换期间网站暂时不可用，耗时与录音和语音模型的数据量有关；构建失败时原网站继续运行。

## 2. 查看结果

```bash
sudo tail -n 30 /opt/nihongo/update-v1.1.2.log
```

最新任务末尾出现 **`UPDATE_OK v1.1.2`** 后，确认正在运行的版本：

```bash
cd /opt/nihongo
sudo docker compose -p nihongo-web -f compose.yaml ps
sudo docker compose -p nihongo-web -f compose.yaml exec -T app \
  node -p 'require("./package.json").version'
```

应显示应用 `healthy` 和版本 `1.1.2`。打开原来的网址，电脑按 `Ctrl + F5`，进入「听懂 → 教材原声」，检查快退／快进及空格操作。手机重新加载页面后检查播放、暂停和录音回听。

若没有成功标记或命令报错，查看最新日志。切换后的错误会触发恢复旧镜像；自动恢复也可能因 Docker 或磁盘故障失败，因此以日志和实际容器状态为准。不要把“后台任务已启动”当成“新版本已运行”。

## 保存了什么

运行配置继续使用 `/opt/nihongo` 中的 `.env`、`compose.yaml`、`deploy/Caddyfile` 和 `server-data`。IP HTTPS、网页登录、API 密钥、语音模型和学习记录沿用原配置；不会把 Git 中的网关模板复制到运行目录。

停止应用后，脚本备份上述数据和配置，并验证备份可读取；备份路径会出现在日志里。旧镜像保留为回退镜像。备份包含私有配置，请留在服务器私有目录。

## 手动回退

本版没有数据库结构变更，回退镜像时继续使用现有学习数据。将 `backup_dir` 改为日志中打印的备份目录：

```bash
(
set -e
backup_dir=/opt/nihongo-backup-v112-替换为实际后缀
old_image=$(sudo cat "$backup_dir/old-image.txt")
sudo docker image inspect "$old_image" >/dev/null
sudo docker tag "$old_image" nihongo-web:local
cd /opt/nihongo
sudo docker compose -p nihongo-web -f compose.yaml up -d \
  --no-build --pull never --no-deps --wait --wait-timeout 180 app
sudo docker compose -p nihongo-web -f compose.yaml exec -T app \
  node -p 'require("./package.json").version'
)
```

不要在 `/opt/nihongo-src` 运行 Compose，也不要用旧备份覆盖当前学习数据。完整数据备份用于故障恢复，正常回退只切换镜像。
