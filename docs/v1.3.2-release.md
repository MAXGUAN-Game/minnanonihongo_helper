# v1.3.2：单元等级卡片与 AI 练习改进

先把 `releases/nihongo-web-v1.3.2.tar.gz` 和同名 `.sha256` 文件上传到服务器 `/tmp`，再执行下面的更新命令。

本次交付为本地源码部署包，不会自动更新远程服务器。上传约 1 分钟，服务器构建通常需要 5～20 分钟；原 v1.3.0、v1.3.1 发布包保留。

## 本次发布内容

- 课程地图每张单元卡显示总进度百分比及进度条，取单词、语法、听力、口语四模块的平均值，最多保留一位小数。0% 为灰卡，超过 0% 且不足 30% 为铜卡，30% 至不足 70% 为银卡，70% 至不足 100% 为金卡，100% 为钻石卡。右上角仅显示等级图标，悬停和屏幕阅读器可读取名称；灰卡仍可进入学习。当前选择单独标记，保留等级颜色。
- 所有拼写练习回车提交；答对后再按一次回车可进入下一题，不重复评分。默认停留当前题，可打开「回车答对自动下一题」。修改已评答案后重新提交；输入法确认键和长按回车不误跳题。片假名接受平假名或片假名，AI 单词不受教材限制，答对后显示中文释义。
- 所有 AI 无限练习在首题后后台准备最多 5 道待答题，消耗后异步补齐；切换模块或离开时取消等待。AI 分析后的参考表达默认展开，标注考点和来源单元。
- 单词进度按已掌握词数计算，可手动勾选或累计答对 3 道不同 AI 题；已掌握词不再出题。听力、口语按达标题数 / 100 计算，同题不重复计数；进度条显示完成数与总数。
- 支持保存手动进度基线，后续实际学习继续累计；导航和备份恢复保留基线。手动进度不伪造词汇掌握或答题记录，模块中标注实际完成数。

## 更新服务器

适用于现有 `/opt/nihongo` 标准部署；支持已安装的 1.1.0、1.1.1、1.1.2、1.2.0、1.3.0、1.3.1 和 1.3.2。沿用原服务器的 Docker Compose、Node、systemd 及 `flock`、`tar`、`mktemp`。共存部署请使用其独立流程，见 [共存部署说明](deployment-shared.md)。

1. **上传两个文件，约 1 分钟。** 在电脑打开 `C:\LanguageMaster\releases`，用服务器面板文件管理上传到服务器 **`/tmp`**，保留文件名，无需手动解压：

   ```text
   nihongo-web-v1.3.2.tar.gz
   nihongo-web-v1.3.2.tar.gz.sha256
   ```

2. **启动后台更新，构建预计 5～20 分钟。** 在服务器终端整段执行：

   ```bash
   (
   set -e
   cd /tmp
   sha256sum -c nihongo-web-v1.3.2.tar.gz.sha256
   src=$(sudo mktemp -d /opt/nihongo-v132-src-XXXXXXXX)
   sudo tar -xzf /tmp/nihongo-web-v1.3.2.tar.gz -C "$src"
   sudo test -f "$src/src/client/CourseMap.tsx"
   sudo systemd-run --unit=nihongo-update-v132 --collect \
     --service-type=exec --property=UMask=0077 \
     --property=TimeoutStopSec=300 \
     --property=StandardOutput=append:/opt/nihongo/update-v1.3.2.log \
     --property=StandardError=inherit \
     /usr/bin/bash "$src/deploy/update-release.sh" /opt/nihongo
   )
   ```

   `Running as unit...` 只表示已启动，还需要等待下一步的完成标记。

3. **查看更新结果。** 执行：

   ```bash
   sudo tail -n 40 -f /opt/nihongo/update-v1.3.2.log
   ```

   等本次 `UPDATE_START v1.3.2` 之后出现 **`UPDATE_OK v1.3.2`**，按 Ctrl+C 退出日志。日志会追加，不能把旧记录当成本次成功。如果出现 `UPDATE_FAILED` 或 `ROLLBACK_FAILED`，保留错误输出与备份目录，先处理错误。

4. **核对容器版本。** 执行：

   ```bash
   cd /opt/nihongo
   sudo docker compose -p nihongo-web -f compose.yaml exec -T app node -p 'require("./package.json").version'
   ```

   输出应为 **`1.3.2`**。

5. **刷新网站。** 按 Ctrl+F5；课程地图应出现彩色等级卡、图标和进度条。进入片假名练习，确认回车提交、答对后再次回车进入下一题。

## 学习记录与回滚

升级脚本先构建新镜像，再停止应用写入并备份数据库及登录、网关配置，备份目录前缀为 `nihongo-backup-v132-`。只切换应用容器，原登录配置、网关、学习记录和密钥保留。失败时恢复兼容的数据库快照与旧镜像；不要单独把旧镜像套在新版写入的数据库上。

**本机 27、28、29 单元的 70% 设置属于本机学习数据，不会随源码包同步到服务器。** 更新后服务器按其已有学习记录计算卡片进度；本次发布不会覆盖服务器成绩。

学习备份仍为 v4，支持既有 v1～v4 备份。含手动进度的新备份需使用支持该字段的版本读取。录音仍只保存在当前页面；从较旧版本升级时，程序会按既有规则清理其管理的历史录音和关联。外部备份不会被修改。
