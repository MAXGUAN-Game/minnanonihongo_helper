# v1.7.0

- 专项练习侧栏入口显示段位颜色与小段位徽标，覆盖黑铁、青铜、白银、黄金、钻石、棱彩；答题后自动刷新，棱彩仍不分小段。
- 增加 English，并保留中文、日本語。语言偏好保存在当前浏览器。
- 固定翻译资源覆盖 50 课标题、目标、语法说明、例句释义，以及 2,258 个词条的释义和详情、页面控件与说明。资源不改变题目 ID、课次、标准答案或学习记录。
- 日语题目、原文、读音、用户回答、语法中的日语变形及发音保持原样。切换语言只改变显示用的说明和释义，不改变判题内容。
- 新产生的 AI 反馈按界面语言翻译，复用现有 DeepSeek 配置，并缓存到独立的 localization-cache 内容目录。固定翻译不依赖实时 API；动态翻译失败时显示对应语言的错误及重试按钮，不冒充翻译成功。
- 发布继续完整备份远端数据与配置，核对历史记录、持久化挂载和登录认证后恢复访问。
