# v1.5.0：专项练习

主导航新增默认收拢的「专项练习」，展开包含时分、年月日、个数、数字、价格。每项仅有听力-AI练习、口语-AI练习两个模式，复用单元课的听写、录音评分、拼写评分、预取换题、回车操作、播放器与语音设置。

题库是可重复练习的受限短语题库，而非让模型自由生成完整句子。随机抽题避开同类最近30题；模型继续负责非完全一致写法的听写判定和口语评分。出题不消耗 DeepSeek 调用，评分仍使用已有配置。口语评分明确不因短语缺少主语、谓语、句尾而扣分。

| 分类 | 内容 |
| --- | --- |
| 时分 | 1至12点、0至59分、上午／下午、几点到几点 |
| 年月日 | 年份、月份、日期、完整年月日及日期范围 |
| 个数 | 1至10的通用数法、1至99個及范围 |
| 数字 | 常用整数、百千万位与范围 |
| 价格 | 日元价格及价格范围 |

参考读音核对：[国际交流基金的数词资料](https://www.kyozai.jpf.go.jp/kyozai/material/BTS00009/ja/render.do)、[京都大学「四」读音资料](https://www.samidori.k.kyoto-u.ac.jp/study/exam?id=252)、[国际交流基金日期教学资料](https://ba.jpf.go.jp/wp-content/uploads/2025/08/Teacher-Manual-Vol.2-2017-JP-2024.05.13.pdf)。题库为程序生成的原创短语组合。

专项记录使用独立 topic 与 special:topic:kind 位置键，不复用任何现有课程ID或位置键。内部 lessonId=0 仅允许带合法 topic 的专项记录；原有1至50课及其历史映射不变。专项不进入课程掌握度或已练课程采样。现有JSON表增量写入，无SQL结构迁移、初始化替换或历史重写。备份保留专项题目、答题和10个位置，恢复时验证类别及题库关联，拒绝串题。

验证覆盖题库读音和日期、十个独立练习位置、预取与激活、幂等请求、数据库重启、备份恢复与损坏备份拒绝、文字和录音评分、真实浏览器完整导航及桌面／手机布局。测试只使用临时数据库和隔离服务。
