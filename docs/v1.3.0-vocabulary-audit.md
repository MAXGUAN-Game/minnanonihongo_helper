# v1.3.0 词库核对记录

按《大家的日语》第二版整理 1～50 课词汇与固定表达，合计 2258 条。各课数量包含专名、不同读音或义项、阅读部分新增词；同形同义重复项合并，因此数量不等于纸书排版行数。中文义项独立整理，不收录教材例句或每词五例句。

交叉来源：[Langoal 分课词表](https://langoal.com/ja/vocabulary)、[初级Ⅰ整理表](https://nihongopic.com/minnanonihongo-word/)、[初级Ⅱ整理表](https://nihongopic.com/nihongo-word/)。阅读标题歧义另核对[出版方第二版阅读索引](https://www.3anet.co.jp/np/secure/0-0001-03-240011/0-0001-03-240011-1.pdf)。

来源中混入的旧版条目按第二来源逐项核对；每课 `reviewNotes` 记录表记、读音与版本处理，审计文件保存主来源每项对应的词条键或排除理由。第 35 课「株」校正为「朱」，第 37 课「眠り姫」校正为「眠り猫」，依据出版方阅读索引。
