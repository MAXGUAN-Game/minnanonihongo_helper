# v1.4.5：Haruka 独立选项

日语朗读设置提供本机、MiniMax、Haruka 三选一，保存后按选择播放。移除设备自动优先 Haruka 开关，避免实际声音与 MiniMax 选中状态不一致。保留现有 MiniMax 密钥、音色和语速。

Haruka 使用用户确认过的原文和完整时间表达输入，支持保存的语速及播放控制；单词播放也遵循选择。设备缺少 Haruka 时禁用选项并明确提示，已保存 Haruka 的其他设备不会静默改用其他声音。

验证覆盖设置保存和重新加载、切换引擎、旧偏好兼容、例句和单词、缺少声音、移动端宽度、后端重启保留配置及实际 Windows Haruka 播放。测试仅使用隔离浏览器和临时数据库。

无数据库结构迁移。发布沿用远端数据与认证配置，暂停写入后备份并比较历史摘要。
