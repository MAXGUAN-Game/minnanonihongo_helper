# v1.8.0

- 全局主色改为蓝色 #102ba6，并调整原绿色背景、边框、按钮和选中态。段位颜色保持独立。
- 品牌区仅保留火箭 Logo，去掉侧栏与顶栏的品牌文字；同步更新网站图标。
- 每个日语朗读播放器增加独立引擎选择：跟随全局设置、本机声音、MiniMax、Haruka。覆盖仅保存在当前页面对应的播放器中，不写全局设置；离开播放器后释放。
- 切换引擎会停止当前播放，下次播放或重放使用新引擎。显式选择的引擎失败时报告错误，不自动换成其他引擎。
- 教材 MP3 和录音显示不可切换的“原始音频”；中文讲解维持现有本机语音能力，不显示无效的日语引擎选择。
- MiniMax 合成接口接受仅本次请求的 provider 覆盖；密钥、音色、质量及学习记录均保持原有配置。
